# Checkpoint 7: Motivate the Bundler

Do not install anything yet. Ask:

> The browser can run modules now, so why do people still use bundlers?

Explain that production often needs fewer optimized files, hashed filenames for caching, minification, tree shaking, lazy chunks, CSS/asset processing, and consistent handling of `node_modules` dependencies.

Use this definition:

> A bundler automates the transformation from developer-friendly source modules to runtime-friendly output chunks.
