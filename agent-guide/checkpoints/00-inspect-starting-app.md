# Checkpoint 0: Inspect the Starting App

Do not edit anything yet.

Explain that `index.html` links `styles.css`, loads `app.js`, and the browser executes the JavaScript directly with no build step. This is the simplest valid frontend setup.

Ask the learner to open `index.html` in the browser and click the buttons. Then ask whether they are ready to split logic into more files.
